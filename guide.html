Accéder à l'application
Tous les joueurs

Chroniques est une application web accessible depuis n'importe quel navigateur, sur ordinateur ou téléphone. Aucune installation requise.

🔗 URL de l'application

Votre Maître de Jeu vous communiquera l'adresse. Elle ressemble à :
sachaloi.github.io/chroniques-jdr/

L'application fonctionne entièrement dans le navigateur. Vos données sont synchronisées en temps réel entre tous les joueurs connectés à la même session.
🚪
Rejoindre une session
Joueur
  • 1Ouvrez l'URL de l'application dans votre navigateur.
  • 2Dans le champ Code de salon, tapez le code à 6 caractères fourni par votre MJ (ex. AB3K7Z).
  • 3Appuyez sur Entrée ou cliquez Rejoindre →.
  • 4La liste des personnages de la session s'affiche. Cliquez sur le vôtre pour ouvrir votre fiche.
Si votre personnage n'existe pas encore, cliquez sur + Nouveau personnage pour le créer. Votre MJ peut aussi le créer pour vous depuis la Vue MJ.
🕐
Sessions récentes
Tous

Après votre première connexion à une session, elle apparaît automatiquement dans la section Sessions récentes en bas de l'écran d'accueil. Il vous suffit de cliquer dessus pour y retourner sans retaper le code.

🟡 Badge MJ   🔵 Badge Joueur

Chaque session affiche un badge indiquant votre rôle. Les sessions où vous êtes MJ affichent le bouton Vue MJ et 🎨 Thème — ces boutons sont invisibles pour les joueurs.

L'historique est enregistré dans votre navigateur. Si vous changez de navigateur ou d'appareil, vous devrez retaper le code.
⚙️
Créer une session
Maître de Jeu
  • 1Sur l'écran d'accueil, saisissez le nom de votre campagne dans le champ Nom de la campagne.
  • 2Cliquez sur Créer la session.
  • 3Un code à 6 caractères apparaît en haut à droite — c'est le code à partager à vos joueurs.
Créez vos personnages à l'avance depuis la Vue MJ pour que vos joueurs n'aient qu'à cliquer sur leur nom en arrivant.

Choisir un thème de campagne

Cliquez sur le bouton 🎨 Thème dans le header pour sélectionner l'ambiance visuelle. Le thème s'applique instantanément à tous les joueurs connectés.

Les 5 thèmes disponibles

Médiéval Fantastique — Royaumes anciens, magie et épopées.
SteamPunk — Vapeur, engrenages et cuivre brûlant.
Futuriste / Digital — Néons, code et IA.
Spatial — Cosmos infini et nébuleuses.
Mystérieux — Ombres, secrets et horreur douce.

La fiche de personnage
Joueur

Statistiques (3 × 3)

Votre personnage possède 9 caractéristiques réparties en trois catégories :

⚔️ Physique

Force · Dextérité · Résistance

🗣️ Social

Présence · Manipulation · Sang-froid

🧠 Mental

Intelligence · Astuce · Résolution

Chaque stat est représentée par des cercles (dots). Cliquez dessus pour modifier la valeur. Cliquer sur le dernier cercle rempli le vide (diminue d'un).

= valeur naturelle 3/5
= +2 via objet magique (total 5)
Le maximum naturel est 5. Un objet magique équipé peut pousser une stat jusqu'à 7 — les dots violets représentent ces bonus.

Points de vie

Utilisez les boutons −5 −1 +1 +5 pour modifier vos PV en temps réel. La barre change de couleur : verte au-dessus de 50 %, dorée entre 25 et 50 %, rouge en dessous.

Or 💰

Compteur de pièces d'or. Modifiez-le directement en tapant une valeur ou avec les boutons −10/−1/+1/+10.

Capacités & Consommables

Cette section liste vos capacités à usage limité (pouvoirs, potions, sorts physiques…). Chaque item affiche ses charges restantes / charges de session.

  • ▸ Utiliser — dépense une charge.
  • ▸ ↺ — restaure une charge manuellement.
  • ▸ ↺ Nouvelle session — remet toutes les charges au maximum d'un coup.

Le Guildeur & le Loom
Joueur

Le Loom est l'énergie magique qui imprègne le monde. Chaque personnage porte un Guildeur Constellé — un bijou taillé dans de l'écume servant de réservoir à cette énergie.

Choisir son école

Sur votre fiche, cliquez sur l'une des 5 orbes colorées pour lier votre Guildeur à cette école. Ce choix définit quelle couleur de Loom vous pouvez canaliser.

Charges de Loom

Les charges représentent l'énergie accumulée dans votre Guildeur. Utilisez les boutons + et − pour les gérer. Il n'y a pas de maximum — vous pouvez en accumuler autant que vous en trouvez en jeu.

📖 Lire le Loom

Vous apprenez un nouveau sort. Votre MJ l'ajoute à votre liste de sorts connus depuis la Vue MJ. Une fois appris, il reste permanent.

⚡ Récolter le Loom

Vous accumulez de l'énergie dans votre Guildeur. Augmentez vos charges manuellement. Ces charges serviront à lancer vos sorts.

Lancer un sort

  • 1Cliquez sur ⚡ Sorts disponibles — seuls les sorts de votre école dont le coût est ≤ vos charges actuelles s'affichent.
  • 2Cliquez sur Lancer pour dépenser les charges et activer le sort.
  • 3Cliquez sur 📜 Tous mes sorts pour consulter l'ensemble de vos sorts connus, même ceux que vous ne pouvez pas encore lancer.
Un sort grisé signifie que vos charges sont insuffisantes. Récoltez davantage de Loom avant de tenter de le lancer.

Inventaire & Échanges
Joueur

L'inventaire affiche vos objets sous forme de grille de slots. Par défaut vous avez 10 emplacements. Posséder un sac dans votre inventaire l'étend à 30 emplacements.

⚔️Épée
🧪Potion
🎒Sac

Le contour doré indique un objet équipé. ✦ violet = objet magique.

Équiper un objet

  • 1Cliquez sur l'objet dans la grille.
  • 2Dans la fenêtre de détail, cliquez sur Équiper.
  • 3Les stats sont immédiatement mises à jour si l'objet est magique et confère des bonus.
Vous pouvez déséquiper un objet en cliquant à nouveau dessus. Il reste dans l'inventaire mais ses bonus ne s'appliquent plus.

Objets magiques ✦

Les objets rares ou uniques définis par le MJ peuvent conférer des bonus à vos statistiques. Un dot violet apparaît alors à côté de la stat concernée, ainsi qu'un badge +X.

Attention : même avec les bonus, une stat ne peut jamais dépasser 7.

Donner un objet à un autre joueur 🤝

  • 1Cliquez sur 🤝 Donner en haut de l'inventaire (ou dans le détail d'un objet).
  • 2Dans la colonne gauche, cliquez sur les objets à transférer — ils passent dans la colonne droite À envoyer.
  • 3Sélectionnez le destinataire dans la liste déroulante.
  • 4Cliquez Envoyer →. Les objets apparaissent immédiatement dans l'inventaire du destinataire.
Si l'inventaire du destinataire est plein, le transfert est bloqué. Il doit d'abord jeter ou envoyer des objets.

Maître de Jeu uniquement

Accès réservé
Le bouton Vue MJ n'est visible que sur le navigateur qui a créé la session. Les joueurs n'y ont pas accès.

Tableau de bord des personnages

La Vue MJ affiche en temps réel une carte pour chaque personnage avec ses PV, son Guildeur et ses consommables.

Bibliothèque d'objets

Créez, modifiez et supprimez les objets disponibles dans votre campagne. Vous pouvez :

  • ▸ + Nouvel objet — créer un objet avec nom, catégorie, icône, description. Cocher Objet magique pour ajouter des bonus de stats.
  • ▸ 📦 Importer le thème — charge les 10 objets pré-définis du thème choisi (MedFan, SteamPunk…) en un clic. Les doublons sont ignorés.
  • ▸ Donner — assigne directement un objet de la bibliothèque à un personnage.

Bibliothèque de sorts

Créez les sorts disponibles dans votre campagne — nom, école, coût en charges, description. Vous êtes le seul à pouvoir créer des sorts et les attribuer.

  • ▸ + Nouveau sort — définissez l'école (couleur de Loom), le coût et la description.
  • ▸ Assigner — donne un sort à un personnage. Il apparaît dans sa liste de sorts connus.
Importez d'abord les objets du thème avant la session. Ça évite de créer les potions et armes de base à la main à chaque campagne.
Créez quelques sorts à l'avance pour avoir de quoi récompenser les joueurs qui lisent le Loom pendant la session.

Résumé des actions MJ

Avant la session

1. Créer la session → noter le code.
2. Choisir le thème de campagne.
3. Importer les objets du thème.
4. Créer les sorts de la session.
5. Créer les personnages des joueurs.

Pendant la session

▸ Distribuer objets et sorts via les boutons Donner / Assigner.
▸ Surveiller les PV et consommables en temps réel depuis le tableau de bord.
▸ Demander aux joueurs de gérer leur Guildeur eux-mêmes.

Fin de session

▸ Chaque joueur clique sur ↺ Nouvelle session pour réinitialiser ses consommables.
